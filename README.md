# react-whatsap-chat (via green-api.com)

## Установка необходимого ПО

1. Установить Node.js версии [22.22.2] (https://nodejs.org/download/release/v16.16.0/) (npm установится вместе с Node.js)  

2. Перейти в корень проекта и выполнить команду `npm i` (этой командой установятся npm-пакеты)

## Запуск сервера разработки и открытие приложения

1. Запустить в терминале команду `npm run dev`

2. Перейти по URL который появится после запуска dev сервера в терминале (http://localhost:5173/)

## Вход в приложение

1. Создайте учетную запись в сервисе https://green-api.com/

2. Создайте инстанс на странице https://console.green-api.com/

3. Введите учетные данные (apiUrl, idInstance, apiTokenInstance) со страницы своего инстанса в соответсвующие поля на странице логина в приложении
